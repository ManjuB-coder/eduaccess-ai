# EduAccess AI 🎓🤖

EduAccess AI is an AI-powered accessibility and learning assistant designed to make education more inclusive, interactive, and accessible for students. The application helps users understand complex educational content through AI-based simplification, translation, chatbot assistance, and audio learning features.

---

## 🚀 Features

### 📖 AI Content Simplification
Simplifies difficult educational content into easy-to-understand language for better learning and accessibility.

### 🌍 Multi-language Translation
Translates educational content into different languages to support diverse learners.

### 🤖 AI Chatbot Assistant
Provides instant AI-powered academic assistance and answers student queries interactively.

### 🔊 Audio Learning
Converts educational content into audio for auditory learners and accessibility support.

### 🎥 Live Lecture Support
Provides support for interactive and accessible live learning experiences.

### 👤 User Authentication
Secure login and signup functionality for users.

### 📚 Classroom Dashboard
Interactive dashboard for accessing learning features and classroom modules.

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/ManjuB-coder/eduaccess-ai.git
```

### Navigate to Project Folder

```bash
cd eduaccess-ai
```

### Install Flutter Dependencies

```bash
flutter pub get
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Run Backend Server

```bash
node server.js
```

### Run Flutter App

```bash
flutter run
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder and add:

```env
GROQ_API_KEY=your_api_key_here
```

## 🎯 Problem Statement

Many students face difficulties in understanding complex educational content due to language barriers, accessibility limitations, and lack of personalized support. EduAccess AI aims to bridge this gap using AI-powered accessibility solutions.
